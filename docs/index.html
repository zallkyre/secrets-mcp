How it works

01

Paste

The agent sees a key and calls stage_secret with the text.

02

Swap

Threat model

The part most tools hide

This cannot un-send a key. The moment you paste it, it reached the model provider on that request. Nothing local can undo that.

What it does close: the key being written into shell commands, curl calls, files, logs, or later prompts. That is where most leaks actually happen.

Treat it as blast-radius reduction, not a vault you can paste anything into. If a live key was exposed, rotate it.
